A new way for engineers to share and build experience. Agents turn any blog, incident or concept into a simulation that brings you closer to reality, and saves you the reading.

experienceencodeplaybook.jsonrunsimulation ↗

The problem
  • There's a gap between reading about a system and experiencing it live.
  • Simulations close that gap. Not exact, but much closer.
  • Agents make it fast: one story in, one simulation out.

An example

How to create playbooks

The story-to-playbook skill turns a blog post, postmortem, concept or short prompt into a validated playbook.json. Install it once:

npx skills add smarchone/sim-xp --skill story-to-playbook -g

Then give it a story in Claude Code:

/story-to-playbook https://github.blog/news-insights/company-news/oct21-post-incident-analysis/
/story-to-playbook "Postgres as a job queue, load tested until it breaks"
/story-to-playbook "How a Kafka consumer rebalance storm starts and ends"

Open the file in the player (drop it on the page, or Open file… in the side panel) and press Space.

Share your playbook library

A library of playbooks can be hosted as a public GitHub repo.
eg: the default library, smarchone/sim-xp@main/v3/playbooks

Import it in the player:

side panel → Library → type the repo name → Add

Can also run a playbook directly via URL eg:

https://smarchone.github.io/sim-xp/v3/#smarchone/sim-xp@main/v3/playbooks:postgres-queue-load-test
