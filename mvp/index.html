Let Claude Code play this
  1. Add the WebMCP bridge to Claude Code
    claude mcp add webmcp -- npx -y @smarchone/webmcp-bridge
  2. Ask Claude to play a drill
    claude "Open https://smarchone.github.io/sim-xp/ with the webmcp tools and play the gc-death-spiral drill"

Run both in the same folder. Requires Node 22+ and Chrome. Other MCP agents (Codex, Gemini CLI, Cursor, VS Code) work too: add the bridge to their MCP config.

Advanced: slash commands

Install these, then run /run-drill to play, or /write-playbook "your incident story" to turn your experience into a new drill.

  1. /run-drill
    mkdir -p .claude/commands && curl -fsSL https://smarchone.github.io/sim-xp/commands/run-drill.md -o .claude/commands/run-drill.md
  2. /write-playbook
    mkdir -p .claude/commands && curl -fsSL https://smarchone.github.io/sim-xp/commands/write-playbook.md -o .claude/commands/write-playbook.md
