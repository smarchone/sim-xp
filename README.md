# sim-xp

Learn systems by watching them in motion.

- **[v2](v2/)**: a story becomes a playbook that plays as components, dashboards and a feed, pausing at the
  moments that explain it. Claude Code writes the playbook with the `/story-to-playbook` command and plays it
  through WebMCP. Live at https://smarchone.github.io/sim-xp/v2/
- **[MVP](mvp/)**: incident drills you operate yourself. Live at https://smarchone.github.io/sim-xp/
