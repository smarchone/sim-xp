      Add a library

      A library is a GitHub repo, or a folder in one, that holds playbook .json files and an index.json listing them. Paste its GitHub link:

      A folder works too: github.com/owner/repo/tree/branch/folder. Or write owner/repo, or owner/repo@branch/folder. Example: smarchone/simxp-playbooks. How to make one

      Add your own playbook

      A playbook is a .json file that tells a story about a system. Here is how to make one; yours are kept in Your playground.

      Install the skill

      Add the story-to-playbook skill to Claude Code. Run this in a terminal:

      npx skills add smarchone/sim-xp --skill story-to-playbook -g
