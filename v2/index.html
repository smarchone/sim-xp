    Let Claude Code write one

    The story-to-playbook skill turns a story (a blog post, a postmortem, a one-line prompt) into a checked playbook file. Requires Node 18+.

    1. Install the skill, once
      npx skills add smarchone/sim-xp --skill story-to-playbook -g
    2. Give it a story: a prompt, a postmortem or a blog post URL
      claude "/story-to-playbook why Postgres replicas fall behind during a big backfill"
    3. Drop the playbook file it writes (playbooks/<id>.json) on this page
    Drop the playbook to play it
