    Let Claude Code write and play one

    Claude Code turns a story (a blog post, a postmortem, a one-line prompt) into a playbook, loads it here through WebMCP and plays it. Requires Node 22+ and Chrome.

    1. Add the WebMCP bridge to Claude Code, once
      claude mcp add webmcp -- npx -y @smarchone/webmcp-bridge
    2. Download the /story-to-playbook command, once (rerun to update)
      npx degit smarchone/sim-xp/.claude/commands ~/.claude/commands --force
    3. Give it a story: a prompt, a postmortem or a blog post URL
      claude "/story-to-playbook why Postgres replicas fall behind during a big backfill"
    Drop the playbook to play it
